# Map atmosphere survey

Measured evidence behind the per-map override table in
`src/world/map_atmosphere.cpp` and the emissive palettes in
`src/world/emissive_set.cpp`.

Every figure here was taken from the shipped assets: per-ROW width averages of
each dome's sky-gradient TGA (never a single column -- the gradients bake an
azimuthal sun lobe into the middle of the image), each dome's render_list layer
set, and each map's voxel colour histogram with cluster shapes.

Kept because regenerating it costs hours and because the code comments record
only the conclusions, not the measurements that justify them. Where a survey
figure and the code disagree, the code won: several recommendations were
overruled during implementation, and two -- the horizon clamp on Chicago and
MayanJungle, and the Chicago/SpookyMansion tolerance overlap -- turned out to be
real bugs that now have regression tests.
